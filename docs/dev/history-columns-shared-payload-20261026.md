# 公共数据单次压缩：真实页试验完成，解码开销待降低

将交易号、长度、标志和旧值压缩一次，三种键列分别压缩比较。在原有
128 KiB 页内，三个固定样本的全部 1,817 页验证通过：1,806 个列页均更小，
11 个无法独立恢复注释的普通页保持原样。完整 37 项原始证据已下载并在本机
复算，未剔除任何页。本轮仅新增隔离试验；正式 Go 源码仍为
`3281b8fcd833df0066efba23ac68c6ed329f9a1534ea5be5c75002655b6e9150`
的 2,149 个输入。

| 固定 pair | 页数 | 原页字节 | 原型页字节 | 减少字节 | 编码耗时变化 | 解码耗时变化 |
|---|---:|---:|---:|---:|---:|---:|
| 458 | 622 | 15,459,015 | 15,321,585 | 137,430 | −38.53% | +9.92% |
| 2309 | 615 | 17,420,291 | 17,208,353 | 211,938 | −39.55% | +8.66% |
| 4147 | 580 | 17,137,121 | 16,931,239 | 205,882 | −39.00% | +10.57% |

这些编号是既有发布样本的 pair 索引，交易号范围也不是区块高度。样本来自
原来的 11.8M 固定副本；不能据此推算 25M–35M 全部数据的收益。

页总量从 50,016,427 B 降至 49,461,177 B，减少 **555,250 B**。每个原文件的
控制区均为 `28 × 页数 + 96` 字节；若继续采用同样长度的表、首尾元数据，
三份文件可从 50,067,591 B 估算降至 49,512,341 B，即 **1.1090%**。
原型的 49 字节描述头、两个压缩帧及所有模式字节均计入；尚未实际发布新物理
文件或重写整份库，线上回收量为 0。

每一页先验证旧 V5 编码能够逐字节重现，再核对原型恢复的完整 canonical
字节，包括跨页旧值及不完整头。已有列页的注释由已校验的 HRC2 和原记录
长度恢复。11 个普通页没有推断注释，两种试验路径都只运行普通压缩；其耗时
不能代表实际写入器比较全部候选的成本。

计时是交替次序的三次驻留内存、串行页级诊断。逐轮汇总再取中位数：编码
5.653488246 s → 3.443571677 s（**−39.0894%**），解码
0.563920625 s → 0.620970715 s（**+10.1167%**）。不包含文件读写、ETL、
索引、fsync 或 manifest 发布，不能换算成同步或冷发布提速。

原生 Go 1.25.5 的边界、race、构建和完整真实页测试均通过，耗时分别为
21.58、32.79、4.79、43.25 秒。私有单元实际限制为 2 核、4 GiB、Nice 15；
正式源码、24 个旧辅助源码、试验辅助源码及三份输入的前后校验一致。
构建后二进制 SHA256 为
`484acbb5c0cb2e1f887cb9c01889578c93df1402c57389ffc4a40fd4430f348b`。
原始失败记录也保留：首次环境缺少 `rg`；第二次 systemd 环境缺少 Go 缓存
路径，在编译前被 overlay 检查拒绝。成功试验采用显式 GOPATH、GOMODCACHE
及已有 Go 构建缓存。失败单元未重启，所有目录保留。

新表示仅是未注册的 HSP1 试验，正式策略和读写器没有接入。它没有新的完整
HTTP、MuHash 或快照恢复验收；此前 ordered V5 的成功结果见
[对应报告](history-columns-ordered-pages-20261026.md)，不能混用。
本线程没有推送、部署、启停正式服务、删库或调整正式预算。试验期间正式
服务身份前后均为 inactive/PID 0；这不是对当前服务运行状态的推断。

下一步先降低解码成本。原型分别分配键、公共数据、重组数据和返回值；本地
已实现用一个最多 128 KiB + 36 B 的有界缓冲区直接拼接 HRC2，两个压缩帧
各自仍受精确输出上限约束。边界、错误恢复、八个独立调用方并发及 race
检查通过，尚未测量这一后续实现的真实页性能。原生试验的源码和结果保持
冻结。真实页成本通过后，再评估注册物理格式并重做实际文件、发布、完整
HTTP、MuHash、历史查询和恢复验收。
