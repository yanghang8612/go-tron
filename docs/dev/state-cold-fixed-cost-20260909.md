## 修复内容

### 清单缓存

单条缓存默认保守驻留计费预算由 64MiB 改为 **256MiB**。`GTRON_SNAPSHOT_MANIFEST_CACHE_BUDGET_BYTES` 接受十进制字节，范围 0–1,073,741,824，0 禁用；空值使用默认。原 `GTRON_SNAPSHOT_MANIFEST_CACHE=0/1` 开关保留，禁用时也检查预算格式，非法配置返回错误。这个值不是进程 RSS 或瞬态解码内存上限。

缓存的私有 Segments/Retired 容器精确分配 len 个元素，按照实际持有容量计费，避免 JSON 解码过程中多分配但缓存并不需要保留的空间导致提前拒绝。输入文件容量、对象、字符串及原有双倍保守系数仍计入。新内容拒绝准入时释放无用旧条目；缩小预算或关闭缓存，即使随后读文件失败也释放超预算条目。

仍每次 `ReadFile` 并比较完整当前字节；不凭路径、mtime、generation 或摘要复用。调用者得到可独立修改的副本，production 校验和独立段文件认证不变。新 generation 仍需要完整解码。去掉原 raw 大小预拦后，超预算大清单也要解码并计算完整候选收费；不声称所有 miss 或极大清单路径都更快。

新增 `state/snapshot/cold/manifest_cache/` 下的 `budget_bytes`、`candidate_charge_bytes`、`headroom_bytes`、`rejections/budget`、`last_rejection_charge_bytes`。结合原 hits/misses/bypasses/resident 判断是否命中与是否接近容量上限，未来超过配置预算仍会拒绝，并非无限缓存。

### 状态批量成本

之前按上一批 `BuildDuration + BeforeMergeDuration` 估算单位块/tx 耗时，其中包含每批都要做的清单工作。清单越大、批量越小，固定成本越容易被误当成行密度上升，导致持续缩批。

本轮只扣除直接计时、明确属于元数据的区域：构建前清单与覆盖规划、清单集成发布，以及生命周期中的可信引用登记、裁剪覆盖规划和清单进度更新。真正的历史/事件构建、段内容认证、数据库扫描、删除、批次提交及未分类的工作仍进入批量时间估算。无法回传或不合法的计时保守回退，不以拟合猜测固定成本。

**完整生命周期恢复仍按照全部实际耗时计算**，元数据并非免计费。字节/块/txnum 限制、失败惩罚、取消恢复、硬压力准入和已有截止保留。增长仍每批最多 25%，小整数范围在实际容量允许时可增长 1；未知压力和硬压力不增长。纯元数据的计时精度边界仍是有效样本，不能重置到初始大批量。

新增 `history/budget/density_work`、`density_metadata_work`、`density_total_work`（纳秒）及 `density_measurement`：0 无元数据测量，1 合法实测，2 无效计时保守回退。它们只解释下一批范围；原 `recovery_cost` 继续表示完整外层维护减去独立计费 merge，不能混用。

### 共享调度审计

没有发现永久占锁、空轮询不断延长状态截止或索引预约不释放的证据。索引预约有 10 秒上限、每叶消费、失去资格撤销。索引加速确实增加共享资源竞争，但现有采样不能精确分摊各任务的等待。本轮不同时取消恢复、降低索引份额或新增并行磁盘任务，先验证消除固定成本后的净追赶。

## 本地证据

Apple M1 Max / darwin arm64，`GOMAXPROCS=4`。固定 25,888 active 与 35,532 retired 引用，仅数量来自生产，路径与校验值为合成。长路径样本专门跨越旧容量边界，不称生产清单。冻结旧加载器关键路径与当前加载器使用相同文件，包含 ReadFile、认证、解码或副本返回；首末完整对象比较一致。三次、每次三个操作，取中位数，短测仅用于确定数量级。

| 样本与路径 | 旧 64MiB | 当前紧凑缓存 256MiB |
|---|---:|---:|
| 普通合成路径，重复加载 | 3.796 ms | 3.789 ms，基本不变 |
| 跨预算长路径，重复加载 | 95.036 ms | 4.419 ms |
| 同长路径累计分配 | 83,391,109 B/op | 22,946,616 B/op，减少 72.48% |
| 同长路径首次冷加载 | 94.354 ms | 94.022 ms，基本不变 |
| 同首次冷加载累计分配 | 83,389,322 B/op | 89,787,677 B/op，增加约 7.67% |

长路径 JSON 为 16,545,825 字节；旧候选收费 69,365,568 字节被拒绝，新私有容器收费 67,346,304 字节成功驻留。第一次解码需要新增私有副本，后续重复加载减少分配。缓存命中收益不能按比例换算到持续发布清单时的整节点吞吐，也不是冷文件压缩率提升。

定向缓存、跨预算大目录正确性通过；小 fixture 并发 race 通过（4.043 秒，包含实际并发发布/读取，未重复大目录 race）。成本及现有 load/catchup/lifecycle 定向通过：snapshots/pruning 2.516/9.197 秒；对应 race 3.444/10.647 秒。真实生命周期测试阻塞实际 `Batch.Write` 后释放，确认提交成本留在密度估算和完整恢复中，且热记录实际删除。

原始日志及参数在 `build/benchmarks/20260909-manifest-budget/` 和 `build/benchmarks/20260909-state-cost/history-cost-*`。两个独立只读审查均未发现阻断问题。后续线上验收以同一进程完整窗口内状态净积压与同步影响为准。
