## 问题及改动

8058 的跨块共享降低重复历史写入，昨天至今天的物理 chaindata 已从 523.504 GB
降到 228.147 GB；但冷覆盖之外的历史需要继续保留，完成覆盖的共享 chunk 桶还需独立
退休。原 GC 只机会式尝试取得写锁，忙碌期间可能反复延后。

每轮 GC 的首个完整覆盖候选现在最多排队一次，其余仍 Try；额度在调用前消耗，忙或
错误不返还。使用现有 `GTRON_HISTORY_RANGE_QUEUE=1`，不新增生产开关或更改冷存预算。
保留 1,024 块覆盖证明、获锁后 canonical/Finish/settled prefix 重验、最新物理视图的
完整空桶检查和原子退休。等待次数有界，不是锁等待时延的硬上限。

新增 GC 独立排队 attempts/admitted/busy/errors 和 work total/max。work 仅为退休闭包
墙钟时间；全局 guard 等待/持锁指标还包括热裁剪。没有独立 queued_retired 计数，必须
分别报告排队准入与 GC 退休，不将所有退休绝对归因于排队路径。
