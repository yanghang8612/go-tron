# V5 历史列编码：缓冲复用与公共字段只构建一次

当前是本地完成、服务器固定副本待验收的候选。未推送、部署、重启服务或删除
任何生产/参考数据。默认 `auto` 策略不变，仍需显式选择实验压缩格式。

上一轮真实冷发布对照发现 V5 比 V2 慢约 70–84%，每组多分配约 1.23–1.32 GB。
本次保留普通 Zstd 及三种键编码的完整比较、严格较小才选择的规则和 128 KiB
独立解码边界，只修改串行写入器的临时内存管理：

- TxNum、旧值长度、存在位和旧值字节只构建一次。
- 三种键流共用尾部，变长键前缀从尾部向前对齐，无需重复搬移旧值。
- 每个写入器复用两个 Zstd 输出缓冲及页内记录位置；Reset 清空位置并保留
  有界工作内存。返回压缩结果只借用到下一次编码，现有同步写入路径立即消费。

独立的旧编码函数保持原样，作为逐字节对照。新增测试覆盖三种变换的交错顺序、
压缩后的字节相等、随机/重复键与旧值、极值整数、跨页旧值、部分记录头、存在位
复用、非法输入后恢复、流式写入和 Reset。高密度夹具稳定分配由每页 138 次降至
0 次，保留工作缓冲 520,476 B，低于六页限制。
