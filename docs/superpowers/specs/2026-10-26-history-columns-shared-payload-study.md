Prototype recovery stays within each existing <=128 KiB canonical page, with
no cross-page or owner dependency. Keep opaque previous values unchanged.

all key modes, crossing values/headers, truncation, length overflow and bad

A page-payload study is not a registered physical file, compactor throughput,
full-capture space recovery, HTTP latency or snapshot restore acceptance.

per-page sizes, original/decoded SHA, selected modes, plain-page exclusions,
prototype source and exact overlay binary identity. The current complete native
sources, all inputs, outputs and successful evidence remain immutable.

a registered physical representation, wire it through all writer/read/CLI/
policy/inspection paths and repeat actual file, publication, MuHash, complete

canonical indexes, transaction ranges and commitment semantics. No push,
deployment, production service operation, deletion/reset or budget change.
